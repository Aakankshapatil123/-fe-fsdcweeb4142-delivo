# Delivo Food Delivery Platform

Create a food delivery platform with features for restaurant listings, menu browsing, and order tracking. Implement tools for secure payments, delivery scheduling, and customer feedback to provide a seamless food delivery experience.

# Frontend

# User Authentication

- User Registration and Login
- Secure authentication
- Role-based access for Users, Restaurant Owners, and Admins
- Logout functionality
- Persistent login state


# Restaurant Listings

- Display restaurants with:
  - Restaurant name
  - Location
  - Cuisine
  - Opening hours
  - Ratings
  - Price range
  - Restaurant images
  - Description
- Search restaurants
- Filter restaurants based on available criteria
- View detailed restaurant information


# Menu Browsing

- View restaurant menus
- Display food item:
  - Name
  - Description
  - Price
  - Category
  - Food type
  - Image
- Customize food items using extras
- Add special instructions
- Add menu items to cart


# Cart Management

- Add food items to cart
- Increase and decrease item quantity
- Remove items from cart
- Clear cart
- Calculate item totals
- Calculate cart total
- Support customized items with extras

# Order Management

- Place food orders
- Select delivery details
- Choose delivery type
- Support immediate and scheduled delivery
- View order details
- Track order status
- View order history



# Payment

- Online payment integration using Razorpay
- Support payment options available through the payment gateway
- Display payment status
- View payment history
- Access order/payment receipts



# Notifications

- Display order-related notifications
- Notify users about order status updates
- Mark notifications as read
- Display unread notification count

# Customer Feedback

- Submit restaurant reviews and ratings
- View customer reviews
- Manage submitted reviews
- View restaurant responses where available

# User Profile

- View user profile
- Update profile information
- Upload/update profile picture
- View order history
- View payment history
- Manage notifications

# Restaurant Owner

- Restaurant owner dashboard
- Manage restaurant profile
- Manage menu items
- Add menu items
- Update menu items
- Delete menu items
- Manage restaurant orders
- Update order status

# Admin

- Admin dashboard
- Manage users
- Manage restaurants
- Manage orders
- Manage reviews
- View application statistics
